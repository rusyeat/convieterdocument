Frequently asked questions

What is PaperShift?

A free online toolkit for working with PDF files. Version 0.1 converts PDF documents into editable Word (.docx) files.

Are my files safe?

Yes. Conversion runs in your browser with JavaScript. The file is never uploaded, so nobody else can see it.

Which devices are supported?

Any modern browser on Windows, macOS, Linux, Android or iOS.

Does it work with scanned PDFs?

Not yet. Scanned pages are images with no text layer; OCR support is planned for a later version.

Is it really free?

Yes. There is no sign-up, no trial and no payment.
